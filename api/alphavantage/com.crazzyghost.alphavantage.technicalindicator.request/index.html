alphavantage/com.crazzyghost.alphavantage.technicalindicator.request

Package-level declarations

Fluent request builders for Alpha Vantage's technical indicator endpoints.

com.crazzyghost.alphavantage.technicalindicator.request.TechnicalIndicatorRequest holds the function, symbol, interval and data type every indicator shares. Concrete subclasses add whatever further parameters their indicator requires: com.crazzyghost.alphavantage.technicalindicator.request.PeriodicRequest and com.crazzyghost.alphavantage.technicalindicator.request.PeriodicSeriesRequest add a time period, and com.crazzyghost.alphavantage.technicalindicator.request.SeriesRequest adds a price series field, covering most indicators between them, while com.crazzyghost.alphavantage.technicalindicator.request.SimpleTechnicalIndicatorRequest needs neither and bespoke multi-parameter indicators such as com.crazzyghost.alphavantage.technicalindicator.request.BBANDSRequest, com.crazzyghost.alphavantage.technicalindicator.request.MACDRequest and com.crazzyghost.alphavantage.technicalindicator.request.STOCHRequest each define their own.
