    Technical Indicators (Legacy)

    Deprecated

    .indicator() is deprecated. Use .technicalIndicator() instead — see the Technical Indicators recipe.

    Note

    All Indicator Response provide a getIndicatorUnits() method to acess technical indicator data and getMetaData() to access metadata information

    SMA¶

    AlphaVantage.api()
    .indicator()
    .sma()
    .forSymbol("AAPL")
    .interval(Interval.WEEKLY)
    .seriesType(SeriesType.OPEN)
    .timePeriod(60)
    .onSuccess(e->onData(e))
    .fetch();

    AlphaVantage.api()
    .indicator()
    .sma()
    .forSymbol("AAPL")
    .interval(Interval.WEEKLY)
    .seriesType(SeriesType.OPEN)
    .timePeriod(60)
    .onSuccess { e -> onData(e) }
    .fetch()
